# png-video-render-rules

PNG 슬라이드·MP4 영상을 렌더링할 때 참고하는 규칙. 원본: `02_Knowledge_상세규칙.md.md` (링크 노출 등급 & 오버레이 / Drive 저장 구조 / 최종 출력 체크리스트 중 렌더링 관련 항목).

## 렌더링 엔드포인트

- `server.py` (포트 3333)의 `/generate-png`가 PNG 슬라이드 생성을 담당한다.

## 링크 노출 등급 & 오버레이 문구

플랫폼마다 캡션 내 링크의 노출/클릭 가능 여부가 달라, 오버레이 문구로 보완한다.

| 플랫폼 | 캡션 내 링크 | 우선순위 | 오버레이 문구 |
|---|---|---|---|
| 페이스북 | 즉시노출·클릭가능 | 1순위 | 🔗 게시물 캡션 링크 확인 |
| 유튜브 쇼츠 | 클릭 가능하나 기본 숨김 | 2순위 | 🔗 설명란 링크 확인 (필수) |
| 인스타/틱톡 | 비활성 (bio만) | 보조 | 🔗 프로필 링크 확인 |

- 오버레이는 **6~7번 슬라이드 구간**, **하단 카드 상단부**에 배치한다.
- 기존 카피(특가/CTA 텍스트)와 겹치지 않도록 위치를 조정한다.

## 출력물 구성 (Google Drive 저장 기준)

카테고리별 폴더(화장품/주방용품/생활가전/생활용품/자동차용품/식품) 아래 다음 파일을 생성한다:

- `슬라이드_카피.txt`
- `캐러셀.html`
- `PNG_7장.zip`
- `MP4_초안.mp4`
- `캡션_해시태그.txt`

성과가 좋은 콘텐츠(조회수 1000↑ 또는 저장율 5%↑)는 별표(⭐) 표시된 성과우수 템플릿 폴더에 별도 저장하여 재활용한다.

## 렌더링 체크리스트

PNG/영상 렌더링을 완료하기 전 아래 항목을 확인한다:

- [ ] 슬라이드 7장 구성 완료
- [ ] A/B 2안 모두 반영
- [ ] PNG 7장 zip 생성 확인
- [ ] 블러 배경 확인 (제품 이미지 배경 처리)
- [ ] MP4 렌더링 완료
- [ ] 링크 오버레이 (6~7번 슬라이드, 하단 카드 상단부, 플랫폼별 문구) 적용 확인
